# Data

The pipeline downloads the processed Cleveland subset of the UCI Heart Disease
dataset from the UCI repository on first run and stores it as
`heart_disease.csv`. The downloaded file is excluded from neither Git nor the
analysis; it is small and licensed CC BY 4.0.

Source: https://archive.ics.uci.edu/static/public/45/data.csv  
Citation: Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1989).
*Heart Disease*. UCI Machine Learning Repository.
https://doi.org/10.24432/C52P4X
